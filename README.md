# VJ Stuff

Monorepo for VJ/visual performance projects.

## Projects

### [vj-unreal/](./vj-unreal/)
Real-time VJ animation system built with Unreal Engine 5.4. Audio-reactive visuals, USB camera capture, DMX lighting, and OSC control for live performances.

### [glic-wire/](./glic-wire/)
Port of [GLIC (Glitch Image Codec)](https://github.com/GlitchCodec/GLIC) to Resolume Wire using GLSL/ISF shaders. Real-time glitch video effects for live VJ performances.
